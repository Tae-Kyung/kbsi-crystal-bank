# 단백질 구조 연구 스토리텔링 — 초보자를 위한 가이드

## Google Flow 동영상 제작용 시나리오

---

## Scene 1: 단백질이란?

### 내레이션
> 여러분의 몸속에는 수만 종의 작은 기계가 있습니다.
> 음식을 소화하고, 근육을 움직이고, 병균을 물리치는 기계.
> 이 기계를 **단백질(Protein)**이라고 합니다.

### 비유
- 단백질 = **레고로 만든 로봇**
- 아미노산 = 레고 블록 (20가지 색깔)
- 서열 = 레고 블록의 순서 (설계도)
- 3D 구조 = 완성된 로봇의 모양

### 핵심 메시지
> 단백질의 모양을 알면, 그 단백질이 어떻게 작동하는지 알 수 있고,
> 그 단백질이 고장 났을 때 어떻게 고칠지(약을 만들지) 알 수 있습니다.

### 시각 요소
- 아미노산 체인 → 접히는 애니메이션 → 3D 구조
- 예: KRAS 단백질 (암 관련)

---

## Scene 2: Protein (단백질) — "어떤 기계인가?"

### 내레이션
> 연구가 시작됩니다.
> "KRAS라는 단백질이 암을 일으킨다. 이 단백질의 모양을 알아내자!"
>
> **Protein**은 연구 대상 그 자체입니다.
> 이름, 어떤 생물에서 왔는지, 유전자 이름이 기록됩니다.

### 화면에 표시
```
Protein: KRAS
  유전자: KRAS
  생물종: Homo sapiens (인간)
  기능: 세포 성장 신호 전달
```

### 비유
> 자동차를 만들려면 먼저 "어떤 차를 만들 것인가?" 결정합니다.
> Protein = "만들 차의 종류" (세단? SUV? 스포츠카?)

---

## Scene 3: Construct (구조물 설계) — "어떻게 만들 것인가?"

### 내레이션
> 같은 KRAS 단백질이라도, 만드는 방법은 여러 가지입니다.
> 전체를 만들 수도 있고, 핵심 부분만 잘라서 만들 수도 있고,
> 꼬리표(태그)를 달 수도 있습니다.
>
> 이 각각의 설계를 **Construct**라고 합니다.

### 화면에 표시
```
Protein: KRAS
  ├── Construct A: KRAS 전체 (1-189) + His6 태그
  ├── Construct B: KRAS 핵심 도메인 (1-169)
  └── Construct C: KRAS G12D 변이체
```

### 비유
> 같은 세단이라도 엔진, 색상, 옵션이 다른 여러 "트림"이 있듯이,
> 하나의 단백질에서 여러 Construct를 설계합니다.
> 어떤 Construct가 가장 잘 만들어지고, 결정이 잘 되는지 실험으로 알아냅니다.

### 왜 중요한가?
> Construct 설계가 모든 실험의 성패를 좌우합니다.
> 잘못된 설계 → 단백질이 안 만들어지거나, 만들어져도 결정이 안 됨.
> **KBSI 데이터베이스에는 286,580개의 Construct 설계가 있습니다.**

---

## Scene 4: Expression (발현) — "단백질 공장에서 생산"

### 내레이션
> 설계가 끝나면, 실제로 단백질을 만들어야 합니다.
> 대장균(E. coli) 같은 미생물을 "공장"으로 사용합니다.
> DNA 설계도를 넣어주면, 미생물이 단백질을 대량 생산합니다.

### 화면에 표시
```
Expression:
  숙주: E. coli BL21(DE3)     ← "어떤 공장?"
  벡터: pET-28a               ← "어떤 설계도 틀?"
  유도 온도: 18°C             ← "공장 가동 온도"
  수율: 15 mg/L               ← "얼마나 만들어졌나?"
  결과: 높음 (high)           ← "성공!"
```

### 비유
> 빵을 굽는 것과 비슷합니다.
> 어떤 오븐(숙주)을 쓸지, 몇 도에서 구울지(유도 온도),
> 빵이 얼마나 나왔는지(수율)를 기록합니다.

### 실패하면?
> "단백질이 뭉쳐서 안 녹아요" (insoluble) → 온도 낮추기, 다른 숙주 시도
> "아예 안 만들어져요" (no expression) → 벡터 변경, 코돈 최적화
>
> **이 실패 기록도 KBSI에 저장됩니다! (세계 유일)**

---

## Scene 5: Purification (정제) — "순수하게 골라내기"

### 내레이션
> 공장(대장균)에서 나온 것은 단백질만이 아닙니다.
> 수천 가지 다른 물질과 섞여 있습니다.
> 원하는 단백질만 순수하게 골라내는 과정이 **정제**입니다.

### 화면에 표시
```
Purification:
  방법: Ni-NTA → TEV 절단 → SEC
  최종 순도: 95%
  최종 수율: 10 mg
```

### 비유
> 금광에서 금을 캐는 것과 같습니다.
> 흙과 돌(불순물) 속에서 금(단백질)만 골라내야 합니다.
> 여러 단계의 체(컬럼)를 통과시켜 점점 순수하게 만듭니다.

### 단계 설명
```
1단계: Ni-NTA (자석으로 His 태그 붙은 것만 끌어옴)
2단계: TEV 절단 (태그 제거 — 순수한 단백질만 남김)
3단계: SEC (크기별 분류 — 원하는 크기만 선택)
```

---

## Scene 6: Characterization (특성분석) — "품질 검사"

### 내레이션
> 정제된 단백질이 정말 좋은 품질인지 검사합니다.
> 크기가 맞는지? 뭉쳐있지 않은지? 안정한지?

### 화면에 표시
```
Characterization:
  DLS: 3.2 nm (monodisperse)  ← "크기 균일한가?"
  SEC-MALS: 45.2 kDa (monomer) ← "혼자 있나, 뭉쳐있나?"
  SDS-PAGE: 순도 95%           ← "깨끗한가?"
  열안정성 Tm: 60°C            ← "얼마나 안정한가?"
```

### 비유
> 제품 출하 전 품질 검사(QC)와 같습니다.
> 크기(DLS), 순도(SDS-PAGE), 내구성(Tm)을 확인합니다.
> 검사를 통과해야 다음 단계(결정화)로 갈 수 있습니다.

---

## Scene 7: Crystallization (결정화) — "가장 어려운 단계"

### 내레이션
> 이제 단백질을 **결정**으로 만들어야 합니다.
> 소금을 물에 녹인 후 천천히 증발시키면 소금 결정이 생기듯이,
> 단백질도 특정 조건에서 결정을 만듭니다.
>
> **하지만 이것이 가장 어려운 단계입니다.**
> 수백 가지 조건을 시도해도 대부분 실패합니다.

### 화면에 표시
```
Crystallization:
  침전제: PEG 3350 20%        ← "어떤 용액?"
  버퍼: Bis-Tris pH 6.5      ← "산성도?"
  온도: 18°C                  ← "보관 온도?"
  결과: single_crystal ✅     ← "성공!"

다른 시도:
  침전제: AmSO4 2M, pH 8.0
  결과: precipitate ❌        ← "침전 — 실패"
```

### 비유
> 요리에서 "완벽한 레시피"를 찾는 것과 같습니다.
> 소금 조금 더, 설탕 조금 덜, 온도 5도 낮추면...
> 수백 번의 시도 끝에 드디어 "이거다!" 하는 조건을 찾습니다.

### 왜 실패 데이터가 중요한가?
> 100번 시도해서 1번 성공한다면, 99번의 "이건 안 돼"도 소중한 정보입니다.
> "pH 8 이상에서는 100% 침전된다" → 다른 연구자는 pH 8 이상을 시도할 필요 없음.
>
> **PDB는 성공 1건만 저장합니다.**
> **KBSI는 실패 99건도 저장합니다. 이것이 핵심 차별점입니다.**

### 결과 단계
```
clear (투명)        → 결정 안 됨 (농도 부족)
precipitate (침전)   → 너무 빨리 뭉침 (농도 과다)
phase_separation    → 상분리 (경계 영역)
microcrystal        → 미세 결정 (거의 성공!)
single_crystal ✅   → 단결정 (성공!)
diffraction_quality → 최고 품질 결정 (X선 가능!)
```

## Scene 8: Diffraction (회절) — "X선으로 촬영"

### 내레이션
> 드디어 결정이 만들어졌습니다!
> 이제 이 결정에 강력한 X선을 쏩니다.
> X선이 결정을 통과하면서 특정 패턴으로 흩어집니다.
> 이 패턴을 **회절 패턴**이라고 합니다.

### 화면에 표시
```
Diffraction:
  빔라인: SPring-8 BL41XU     ← "어디서 촬영?"
  해상도: 1.8 Å               ← "얼마나 선명하게?"
  공간군: P212121              ← "결정의 대칭성"
  위상 결정: Molecular Replacement ← "어떻게 해석?"
```

### 비유
> CT 촬영과 비슷합니다.
> 병원에서 X선으로 뼈를 찍듯이,
> 싱크로트론(거대 X선 장치)에서 단백질 결정을 촬영합니다.
> 해상도가 높을수록 (숫자가 작을수록) 더 선명한 사진을 얻습니다.

### 해상도의 의미
```
3.0 Å — 대략적인 모양 (흐릿한 사진)
2.0 Å — 아미노산 수준 (선명한 사진)
1.5 Å — 원자 수준 (초고해상도!)
1.0 Å — 수소 원자까지 보임 (극초고해상도)
```

---

## Scene 9: Structure (구조) — "드디어 모양이 보인다!"

### 내레이션
> 회절 데이터를 컴퓨터로 분석하면,
> 드디어 단백질의 **3차원 구조**가 나타납니다.
> 수만 개의 원자가 어디에 있는지, 어떤 모양인지 알 수 있습니다.

### 화면에 표시
```
Structure:
  방법: X-ray Crystallography
  해상도: 1.8 Å
  PDB ID: 6GOD               ← 전 세계 공유 ID
  등록일: 2018-05-15
  EMDB ID: -                  ← (Cryo-EM일 때만)
```

### 비유
> 설계도를 모르는 기계의 커버를 열고 내부를 들여다보는 것.
> "아, 여기에 이 부품이 있고, 이렇게 연결되어 있구나!"
> → 고장 난 부품을 고치는 약을 설계할 수 있습니다.

### 구조 결정 방법 3가지
```
X-ray (X선 결정학)   — 결정 필요, 가장 높은 해상도
Cryo-EM (전자현미경)  — 결정 불필요, 큰 단백질에 적합
NMR (핵자기공명)     — 용액 상태, 작은 단백질에 적합
```

## Scene 10: Ligands & Bindings (약물 결합) — "약의 열쇠"

### 내레이션
> 단백질의 구조를 알았으니, 이제 약을 만들 차례입니다.
> **Ligand(리간드)**는 단백질에 결합하는 작은 분자입니다.
> 약물 후보가 단백질에 얼마나 잘 붙는지를 **Binding(결합)**으로 측정합니다.

### 화면에 표시
```
Ligand: Sotorasib (AMG-510)
  SMILES: CC1CN(C(=O)C=C...
  MW: 560.6 Da

Binding:
  타겟: KRAS G12C
  IC50: 7.2 nM               ← "얼마나 강하게 붙나?"
  Kd: 3.5 nM                 ← "결합 친화도"
  출처: ChEMBL               ← "어디서 가져왔나?"
```

### 비유
> 자물쇠(단백질)에 맞는 열쇠(약물)를 찾는 것.
> - IC50: "이 열쇠로 자물쇠의 50%를 잠글 수 있는 양"
> - Kd: "열쇠가 자물쇠에 얼마나 단단히 꽂히는지"
> - 숫자가 작을수록 더 좋은 약물 후보!

### 왜 중요한가?
> KRAS G12C에 결합하는 약물 Sotorasib은 2021년 FDA 승인.
> 단백질 구조 → 약물 설계 → 실제 항암제가 된 성공 사례!

## Scene 11: 전체 파이프라인 — "한 눈에 보기"

### 내레이션
> 이 모든 과정이 하나의 파이프라인으로 연결됩니다.

### 화면: 파이프라인 흐름도
```
🧬 Protein        "어떤 단백질?"
    │
🔬 Construct      "어떻게 설계?"
    │
🧪 Expression     "어떻게 생산?"
    │
🔬 Purification   "어떻게 정제?"
    │
📊 Characterization "품질 검사"
    │
💎 Crystallization  "결정 만들기" (가장 어려운 단계!)
    │
📡 Diffraction     "X선 촬영"
    │
🏗️ Structure      "3D 구조 결정"
    │
💊 Ligands        "약물 설계"
```

### 핵심 메시지
> 이 과정에 **평균 6개월~2년**이 걸립니다.
> 가장 큰 병목은 **결정화** — 수백 번 시도해야 합니다.
>
> **KBSI 결정화은행은 이 전 과정의 데이터를 모아서,
> AI가 "다음에 뭘 해야 하는지" 알려주는 시스템입니다.**

---

## Scene 12: KBSI 결정화은행이 특별한 이유

### 내레이션
> 전 세계에 단백질 구조 데이터베이스는 여럿 있습니다.
> 하지만 KBSI 결정화은행은 3가지가 다릅니다.

### 차별점 1: 실패를 기억합니다
```
PDB (기존):  "pH 6.5에서 결정 성공!" (1건)
KBSI:        "pH 8.0 실패, pH 9.0 실패, pH 6.5 성공!" (3건)
             → AI가 "pH 6-7을 먼저 시도하세요" 추천
```

### 차별점 2: 전 과정을 연결합니다
```
PDB:  구조만 저장
KBSI: 발현 → 정제 → 특성분석 → 결정화 → 회절 → 구조 → 약물
      전 과정이 하나의 Construct로 연결
```

### 차별점 3: AI가 실험을 도와줍니다
```
연구자: "KRAS를 결정화하고 싶어요"
AI:     "유사한 단백질 200개를 분석한 결과,
         PEG 3350 20%, pH 6.5, 18°C를 추천합니다.
         성공 확률: 62%"
```

### 마무리 내레이션
> 단백질 하나의 구조를 알아내면,
> 그 단백질 때문에 아픈 사람들을 위한 약을 만들 수 있습니다.
>
> KBSI 결정화은행은 이 여정을 더 빠르고, 더 똑똑하게 만듭니다.
> 실패에서 배우고, AI가 다음 실험을 안내하는 세계 최초의 플랫폼입니다.

## 동영상 제작 가이드

### 형식
- 길이: 5~8분
- 톤: 교육적이지만 친근한 (TED-Ed 스타일)
- 배경음악: 차분한 과학 다큐멘터리 풍

### 각 Scene 시각 요소
| Scene | 시각 요소 | 시간 |
|-------|----------|------|
| 1. 단백질이란? | 레고 블록 → 3D 구조 애니메이션 | 30초 |
| 2. Protein | KRAS 분자 모델 회전 | 20초 |
| 3. Construct | 설계도 분기 다이어그램 | 25초 |
| 4. Expression | 대장균 공장 일러스트 | 30초 |
